A tiny Python program (standard library only, no network) that writes a single patch note — a software changelog entry for a bug in human biology — to `/output/entry.txt`. The brain replays an embarrassing moment from 2014 at 3 a.m. instead of sleeping, so the fix ships in version 2.7.1. A bug every reader recognises at once, in the terse register of a real release note.

> v2.7.1: fixed a bug where the brain replayed embarrassing moments from 2014 at 3 a.m. instead of sleeping.

The entry is one line, 106 characters, within the 160-character limit.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
